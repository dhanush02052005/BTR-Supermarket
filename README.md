# 🛒 BTR Supermarket Management System

The **BTR Supermarket Management System** is a full-featured web application built to streamline daily supermarket operations — including billing, inventory management and smooth navigation.  
---

## 💡 Overview

The system allows supermarket staff to:
- Manage product inventory   
- Track daily sales and stock availability  
- Handle user authentication and role-based access (Admin/Cashier)  

The backend was built to support **real-time data consistency**, **API-driven modular design**, and **secure database communication**.

---

## 🧩 Features

✅ **Inventory Management**  
Add, edit, or delete products with automatic stock updates.

✅ **Billing System**  
Generates detailed bills for each transaction and stores them in the database.

✅ **User Authentication**  
Secure login with role-based access (Admin and Cashier).

✅ **Sales Reporting**  
Daily/Monthly sales summaries for management overview.

✅ **Responsive & Scalable Backend**  
Built to handle multiple store branches and concurrent transactions.
